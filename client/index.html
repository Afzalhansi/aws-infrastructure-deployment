How This Got Deployed

A simplified version of the exact steps used for this deployment.

abdul@local:~$ ssh -i my-key.pem ubuntu@<EC2_PUBLIC_IP> # Connected to the EC2 instance ubuntu@ec2:~$ sudo apt update && sudo apt upgrade -y ubuntu@ec2:~$ curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash - ubuntu@ec2:~$ sudo apt install -y nodejs git ubuntu@ec2:~$ git clone https://github.com/Afzalhansi/aws-first-deployment.git ubuntu@ec2:~$ cd aws-first-deployment && npm install ubuntu@ec2:~$ nano .env # set PORT, DOMAIN, etc. ubuntu@ec2:~$ npm run start 🚀 Server running at http://<EC2_PUBLIC_IP>:3000
