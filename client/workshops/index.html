Workshops I Followed

Guides and hands-on sessions that helped me get this project onto AWS.

01

EC2 Fundamentals

Launching an instance, choosing an AMI, key pairs and instance types (t2.micro on the free tier).

02

Security Groups & Networking

Opening inbound rules for SSH (22) and the app port, and understanding stateful firewall rules.

03

SSH & Remote Server Setup

Connecting with a .pem key, updating packages, and installing Node.js + Git on Ubuntu.

04

Environment Variables

Keeping secrets out of source control using a local .env file loaded with dotenv.

05

Elastic IP

Attaching a static public IP so the server's address doesn't change on restart.

06

Keeping the App Alive

Using PM2 / systemd so the Node process survives after the SSH session ends.
